# FitCoach 3.3.0

Entrenamiento, nutrición y progreso. Incluye 20 métodos de entrenamiento, equivalencias, historial persistente, menús de hasta 30 días y biblioteca ampliada.

Ejecuta `npm run audit` antes de publicar.

Para preparar el paquete web de Capacitor, ejecuta `npm run sync:web`.
El comando recrea `www/` con los archivos de la versión actual y valida el
resultado antes de sustituir la copia anterior.
