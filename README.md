# FitCoach Phase 5

## Novedades reales
- 8 metodologías de entrenamiento:
  - Recomposición 4 días
  - Upper / Lower
  - Push / Pull / Legs
  - Full Body
  - PHUL
  - Powerbuilding
  - Express 45
  - Especialización
- Ajuste de días semanales y duración máxima.
- Aplicación automática de la metodología seleccionada.
- Menús completos según calorías y macros.
- Planes de 1, 3 o 7 días.
- 4 o 5 comidas diarias.
- Prioridad equilibrada, alta en proteína o comidas sencillas.
- Diferencia visible entre el menú generado y el objetivo.
- Lista de la compra automática.
- Selección de fotografías desde la galería del iPhone.
- Opción separada para hacer una foto con la cámara.
- Mantiene Training, Nutrition, Progress y Coach Intelligence.
