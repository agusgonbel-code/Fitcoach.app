Política de privacidad

Actualizada el 28 de agosto de 2026.

Privacidad por diseño

FitCoach 3.4.4 y FitCoach Next procesan localmente el perfil, los entrenamientos, la nutrición, las medidas y, cuando el usuario las añade, las fotografías de progreso. Ninguna de estas versiones envía esos datos a servidores propios ni de terceros.

Datos que recopilamos

No recopilamos datos personales, datos de salud o fitness, fotografías, identificadores, ubicación ni analítica. FitCoach no requiere cuenta, no incorpora anuncios y no realiza seguimiento entre aplicaciones o sitios web.

Almacenamiento local

Los datos se guardan localmente mediante el almacenamiento del dispositivo. En FitCoach Next, las fotografías de progreso se conservan en almacenamiento local de la aplicación y solo salen del dispositivo cuando el usuario exporta una copia o comparte un archivo de forma voluntaria.

Acceso a fotografías

FitCoach Next accede únicamente a las imágenes que el usuario selecciona expresamente para registrar su progreso. No examina ni carga automáticamente el resto de la fototeca.

Copias de seguridad

FitCoach Next permite exportar una copia de seguridad completa bajo el control del usuario. El usuario decide dónde guardarla o compartirla. La restauración valida el archivo antes de sustituir los datos locales y revierte los cambios si el proceso no puede completarse correctamente.

Eliminación de datos

FitCoach Next incluye en Perfil → Datos y privacidad la opción «Borrar todos mis datos». Esta acción elimina del almacenamiento de FitCoach Next el perfil, entrenamientos, registros de nutrición, medidas, borradores, adaptaciones y fotografías de progreso. La eliminación requiere confirmación explícita y no borra automáticamente datos pertenecientes a una instalación legacy de FitCoach 3.4.4.

Servicios externos

La versión nativa de FitCoach Next usa Capacitor para ejecutar la interfaz dentro de iOS. No integra redes publicitarias, analítica remota, cuentas remotas ni procesamiento externo de imágenes.

Cambios y contacto

Si cambia el tratamiento de datos, actualizaremos esta política y la declaración de privacidad correspondiente en App Store. Para solicitar ayuda, utiliza la página de soporte.
